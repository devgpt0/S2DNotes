# 01 - Getting Started and Project Structure

## What, Why, and How

**What:** Spring Framework creates and connects application objects. Spring Boot adds auto-configuration, starter dependencies, an embedded server, and production tooling.

**Why:** Without Boot, every project repeatedly configures compatible libraries, web servers, serialization, and startup. Boot provides working defaults while allowing deliberate overrides.

**How:** Generate a project with Spring Initializr, keep the application class in the root package, add focused starters, run the Maven wrapper, and let classpath plus configuration drive auto-configuration.

## 1) Requirements

- Java 21+
- Maven wrapper generated by Spring Initializr
- Spring Boot 4.1.0

Create projects through `https://start.spring.io` so starter names and build configuration match the selected Boot version.

## 2) Minimal Maven Build

Spring Boot 4 uses the MVC-specific web starter.

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>4.1.0.RELEASE</version>
    <relativePath/> <!-- Result: resolve the parent from configured Maven repositories. -->
</parent>

<properties>
    <java.version>21</java.version> <!-- Result: compile for Java 21. -->
</properties>

<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-webmvc</artifactId>
    </dependency>
</dependencies>
```

Do not specify versions for dependencies managed by Spring Boot.

## 3) Application Entry Point

```java
@SpringBootApplication
public class NotesApplication {
    public static void main(String[] args) {
        SpringApplication.run(NotesApplication.class, args);
        // Output: the application starts and listens on port 8080 by default.
    }
}
```

`@SpringBootApplication` combines configuration, component scanning, and auto-configuration.

## 4) First Endpoint

```java
@RestController
@RequestMapping("/api/greetings")
final class GreetingController {
    @GetMapping
    Map<String, String> greeting() {
        return Map.of("message", "Hello");
        // HTTP 200 JSON: {"message":"Hello"}
    }
}
```

## 5) Run and Verify

```powershell
.\mvnw.cmd spring-boot:run
# Output includes: Started NotesApplication
```

```text
GET http://localhost:8080/api/greetings
# HTTP 200: {"message":"Hello"}
```

## 6) Package by Feature

```text
com.example.notes
|-- NotesApplication.java
|-- product
|   |-- ProductController.java
|   |-- ProductService.java
|   |-- ProductRepository.java
|   `-- Product.java
`-- shared
    `-- ApiExceptionHandler.java
# Result: feature code stays cohesive; the application class remains at the root package.
```

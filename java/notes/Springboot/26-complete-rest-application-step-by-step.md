# 26 - Complete Spring Boot REST Application Step by Step

This chapter connects the individual concepts into one small production-shaped course API.

## 1) What We Are Building

Endpoints:

- `POST /api/courses` creates a course
- `GET /api/courses/{id}` returns one course
- `GET /api/courses?page=0&size=20` returns a bounded page

Rules: title is required and unique, price is positive, invalid input returns Problem Details, writes require `course:write`, and reads require `course:read`.

## 5) Entity

```java
@Entity
@Table(name = "course")
class Course {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 120)
    private String title;

    @Column(nullable = false, precision = 19, scale = 2)
    private BigDecimal price;

    @Version
    private long version;

    protected Course() {
        // Result: JPA can instantiate the entity.
    }

    Course(String title, BigDecimal price) {
        if (title == null || title.isBlank() || price == null || price.signum() <= 0) {
            throw new IllegalArgumentException("invalid course");
        }
        this.title = title;
        this.price = price;
    }

    Long id() { return id; }
    String title() { return title; }
    BigDecimal price() { return price; }
}
```

The entity protects core rules and the database repeats critical integrity constraints.

## 8) Transactional Service

```java
@Service
final class CourseService {
    private static final int MAX_PAGE_SIZE = 100;
    private final CourseRepository courses;

    CourseService(CourseRepository courses) { this.courses = courses; }

    @Transactional
    CourseResponse create(CreateCourseRequest request) {
        if (courses.existsByTitle(request.title())) {
            throw new CourseTitleConflictException(request.title());
        }
        return CourseResponse.from(courses.save(new Course(request.title(), request.price())));
        // Result: one validated course is inserted and mapped to a response.
    }

    @Transactional(readOnly = true)
    CourseResponse find(long id) {
        return courses.findById(id).map(CourseResponse::from)
                .orElseThrow(() -> new CourseNotFoundException(id));
        // Result: response or explicit not-found failure.
    }

    @Transactional(readOnly = true)
    Page<CourseResponse> findPage(int page, int size) {
        if (page < 0 || size < 1 || size > MAX_PAGE_SIZE) {
            throw new IllegalArgumentException("invalid page request");
        }
        return courses.findAllByOrderByIdAsc(PageRequest.of(page, size)).map(CourseResponse::from);
    }
}
```

The uniqueness constraint still handles concurrent duplicate requests; map that database conflict safely.

## 9) Thin Controller

```java
@RestController
@RequestMapping("/api/courses")
final class CourseController {
    private final CourseService service;
    CourseController(CourseService service) { this.service = service; }

    @PostMapping
    @PreAuthorize("hasAuthority('course:write')")
    ResponseEntity<CourseResponse> create(@Valid @RequestBody CreateCourseRequest request) {
        CourseResponse response = service.create(request);
        return ResponseEntity.created(URI.create("/api/courses/" + response.id())).body(response);
        // HTTP result: 201, Location header, and course JSON.
    }

    @GetMapping("/{id}")
    @PreAuthorize("hasAuthority('course:read')")
    CourseResponse find(@PathVariable @Positive long id) {
        return service.find(id);
        // HTTP result: 200 or mapped 404.
    }
}
```

## 10) Error Boundary

```java
@RestControllerAdvice
final class ApiExceptionHandler {
    @ExceptionHandler(CourseNotFoundException.class)
    ProblemDetail notFound(CourseNotFoundException error) {
        return ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, error.getMessage());
        // HTTP result: 404 application/problem+json.
    }

    @ExceptionHandler(CourseTitleConflictException.class)
    ProblemDetail conflict(CourseTitleConflictException error) {
        return ProblemDetail.forStatusAndDetail(HttpStatus.CONFLICT, error.getMessage());
        // HTTP result: 409 application/problem+json.
    }
}
```

## 11) Security

```java
@Bean
SecurityFilterChain security(HttpSecurity http) throws Exception {
    return http
            .authorizeHttpRequests(auth -> auth

            .oauth2ResourceServer(oauth2 -> oauth2.jwt(Customizer.withDefaults()))
```

## How to Practice Each Question

1. Hide the solution.
2. Clarify nulls, duplicates, order, size, failure behavior, and constraints.
3. Explain brute force and complexity.
4. Choose a data structure or pattern.
5. Write and run the solution.
6. Test normal, empty, one-element, duplicate, overflow, and invalid cases.
7. State time/space complexity and production tradeoffs.

## Interview Answer Standard

A complete answer contains:

- clear assumptions
- correct deterministic code
- explicit invalid-input behavior
- expected output
- time and space complexity
- edge cases
- reason for the selected approach
- alternative when scale or requirements change

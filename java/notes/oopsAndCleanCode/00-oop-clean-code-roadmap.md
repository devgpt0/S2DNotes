# OOP and Clean Code - Complete Learning Roadmap

Object-oriented programming organizes behavior around objects with responsibilities. Clean code makes those responsibilities easy to understand, test, and change.

## Learning Order

2. [Encapsulation, invariants, and immutability](02-encapsulation-invariants-and-immutability.md)

## Design Rule

Start with the smallest object model that expresses today’s behavior. Add interfaces, patterns, and layers only when they solve an observed design problem.

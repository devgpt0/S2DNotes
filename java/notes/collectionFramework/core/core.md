## Learning Goals

After this module, you should be able to:

- explain `Collection` and `Map` hierarchy and design intent
- choose the right data structure for workload patterns
- write safe iteration and mutability contracts
- reason about complexity, memory, and thread-safety tradeoffs
- avoid common runtime bugs and design robust collection APIs

## Learning Goal

After completing this module, you should be able to:

- explain `List` contract, mutability models, and implementation tradeoffs confidently
- choose between `ArrayList`, `LinkedList`, `Vector/Stack`, and `CopyOnWriteArrayList` based on workload
- write safe iteration, sorting, stream pipelines, and immutable API boundaries
- avoid common runtime bugs (`ConcurrentModificationException`, overload traps, mutability traps)
- solve list interview and production-style problems with correct complexity reasoning

## Suggested Practice Strategy

- Read each chapter in order.
- Run every code snippet locally and verify outputs.
- Rewrite each snippet once in your own style.
- Solve section `12-interview-and-practice.md` without looking at solutions first.

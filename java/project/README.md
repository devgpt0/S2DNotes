# Java Basics + Collections Projects (Java Use-Case Track)

These projects are for learners who know:
- Java basics
- Java Collections Framework (`List`, `Map`, `Set`, `Queue`)

The project themes are aligned with common Java development usage:
- backend/business modules
- batch processing
- operations/reporting systems

Each project is scoped to 3 to 10 hours and includes:
- functional + non-functional requirements
- passing criteria
- concepts practiced
- HLD and LLD
- implementation roadmap

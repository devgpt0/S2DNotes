# System Design Interview Question Bank

This question bank is ordered from approachable component designs to
open-ended senior designs. It covers backend, frontend, and AI engineering.

> [!NOTE]
> There is no public, reliable, universal list of questions asked by every top
> company. Interview loops also change. This August 2026 curriculum combines
> recurring interview patterns with current production concerns such as AI
> agents, multimodal systems, active-active regions, collaborative clients,
> privacy, evaluation, reliability, and cost.

- [Frontend system design](frontend/README.md)

## Answer every question in this order

```text
clarify scope -> requirements -> estimate scale -> API and data
      -> high-level diagram -> critical flow -> deep dive
      -> failures and scaling -> security -> trade-offs -> summary
```

Read [the interview answer framework](00-interview-answer-framework.md) before
using the solved answers.

## Difficulty labels

| Label | What the interviewer expects |
|---|---|
| Easy | One main flow, sensible API/data choices, and basic scaling |
| Medium | Multiple components, failure handling, and defended trade-offs |
| Hard | Ambiguous scope, distributed correctness, operations, and evolution |

The answers are models, not scripts. State assumptions aloud and adapt when an
interviewer changes the requirements.

# Run the JavaScript examples

This page demonstrates debounce, recursive array flattening, and grouping objects by a property.

```text
examples/
├── 01-debounce/
├── 02-flatten-array/
├── 03-group-by/
├── README.md
├── app.js
├── index.html              # Runs all three examples together
└── styles.css
```

From the repository root:

```powershell
python -m http.server 8002 --directory frontend/quick-study/javascript/examples
```

Open `http://localhost:8002`. Type in the search box, then inspect the displayed
outputs and browser console.

Open a numbered folder from the directory listing to run only that interview question.

# SCSS - Beginner to Expert Roadmap

SCSS is the CSS-like syntax of Sass. Sass runs during development and generates normal CSS for browsers. Browsers do not understand `.scss` directly.

These notes target Dart Sass 1.101.x.

## When to Use SCSS

Use it when modules, reusable calculations, mixins, or build-time generation simplify a real CSS system. Modern CSS already supports custom properties, nesting, color functions, and powerful layout, so do not add Sass automatically.

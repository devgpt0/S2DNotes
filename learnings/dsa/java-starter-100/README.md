# Java Starter 100

This course contains 100 beginner-friendly Java questions for learning
programming, data structures, and everyday Java collection APIs.

Every question has a small problem, an example, a simple idea, a Java 17+
solution, and time/extra-space complexity. Try each problem before looking at
the solution. The notes introduce Java APIs gradually: arrays and String first,
then the collections framework, streams, and core language features.

## How to study

1. Read only the problem and example.
2. Try for 15 minutes without viewing the solution.
3. Write the Java method yourself and test edge cases.
4. Compile with Java 17 or newer.
5. Read the idea and solution only when you are stuck.
6. Solve the same problem again the next day.

## Java reminders

- Use equals for object-value comparison; == compares primitive values or references.
- ArrayList is best for fast indexed access; LinkedList is useful for frequent end operations.
- Prefer Deque with ArrayDeque for stack behavior and Queue with ArrayDeque for FIFO behavior.
- HashMap and HashSet have average constant-time lookup; TreeMap and TreeSet keep values ordered.
- Streams are pipelines and do not mutate the source collection unless your lambda causes side effects.
- List.of and List.copyOf return unmodifiable lists.
- Test empty input, one value, repeated values, null policy, and boundary indexes.

Most snippets assume these imports when needed:

~~~java
import java.io.IOException;
import java.nio.file.*;
import java.time.*;
import java.time.temporal.ChronoUnit;
import java.util.*;
import java.util.function.Function;
import java.util.stream.*;
~~~

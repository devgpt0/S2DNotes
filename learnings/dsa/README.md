# Data Structures, Algorithms, and Competitive Programming

This directory is a progressive path from first principles to advanced
competitive programming.

Algorithm notes derive each optimization from the obvious correct method and
include a visual solved trace. Python contest notes use the same approach for
performance, testing, debugging, and contest decisions.

## Recommended order

1. [Python Starter 100](python-starter-100/README.md) or [Java Starter 100](java-starter-100/README.md) if programming itself is
   still new.
2. [Algorithms and data structures](algorithms/README.md) for reusable ideas,
   proofs, and reference implementations in C++, Python, and Java.
3. [Math for Codeforces 0-2500](math_dsa/README.md) for the mathematics
   progression, recognition cues, and Python references used in contests.
4. [Power 30](power30/README.md) for problem-driven practice.
5. [Competitive-programming hacks](hacks/README.md) for contest execution,
   testing, debugging, and language pitfalls.
6. [ICPC300](ICPC300.md) for ICPC World Finals-level competitive-programming practice.
7. [Focus300](Focus300.md) for senior SWE and AI-engineering interview practice.

```text
syntax -> complexity -> patterns -> data structures -> graphs and DP
                                                        |
                                                        v
                                 mathematics -> strings -> advanced topics
                                                        |
                                                        v
                                      timed practice + post-contest review
```

Reading is not enough. For every concept, explain the invariant aloud,
implement it without looking, and solve at least three problems of increasing
difficulty.

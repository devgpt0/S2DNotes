# Python DSA Starter 100

This course contains 100 very easy Python problems for someone starting data
structures, algorithms, and competitive programming for the first time.

Every problem has its own note with:

- one small problem statement;
- one input and output example;
- a simple explanation;
- a beginner-readable Python solution;
- time and extra-space complexity.

## How to study

1. Read only the problem and example.
2. Try for 15 minutes without viewing the solution.
3. Write the code yourself; do not copy and paste it.
4. Test the example and at least two examples of your own.
5. Read the simple idea and solution only when you are stuck.
6. Solve the same problem again the next day.

The list section deliberately uses lists, indexes, loops, and simple variables
only. Its solutions do not use sets, dictionaries, or tuples.

## Beginner reminders

- A function receives values through parameters and sends its answer back with
  `return`.
- A `for` loop visits values one at a time.
- An `if` statement runs code only when its condition is true.
- List indexes start at `0`.
- Sets store unique values.
- Dictionaries store `key: value` pairs.
- Tuples are ordered values that cannot be changed after creation.
- Always test empty input, one value, repeated values, and already sorted input
  when those cases are valid for the problem.

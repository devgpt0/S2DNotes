# Focus300 011: LeetCode 51 - N-Queens

**Source:** [LeetCode 51](https://leetcode.com/problems/n-queens/)  
**Difficulty:** Hard  
**Pattern:** constraint backtracking with bitmasks

## Exact contract

Given `n` from 1 through 9, return every distinct placement of `n` queens on an
`n x n` board such that no two queens share a row, column, or diagonal. Each
board is a list of `n` strings containing one `Q` per row and `.` elsewhere.
The output order is unrestricted.

## First principles

Place exactly one queen in each row. A choice is legal when its column, its
`row-column` diagonal, and its `row+column` diagonal are unused. Once every row
has a legal choice, the placement is complete; no later validation is needed.

## Step-by-step transformation

1. Choose a start state such as a cell, node, or partial path.
2. Mark the state as visited or temporarily commit the choice.
3. Expand to valid neighbors or next choices while the invariant still holds.
4. Undo the temporary choice when the branch finishes, then return the collected answer.

These problems transform the input into output by exploring one branch at a time and backtracking whenever a branch can no longer produce a valid solution.

## Cases that decide correctness

- `n = 1` has one board.
- `n = 2` and `n = 3` have no boards.
- Every row and column must contain exactly one queen.
- The two diagonal directions require independent conflict tracking.
- Backtracking must undo every recorded choice.

## Brute force: try every column permutation

```python
from itertools import permutations


def solve_n_queens_brute(size: int) -> list[list[str]]:
    if not 1 <= size <= 9:
        raise ValueError("size must be between 1 and 9")

    answers: list[list[str]] = []
    for columns in permutations(range(size)):
        if len({row - column for row, column in enumerate(columns)}) != size:
            continue
        if len({row + column for row, column in enumerate(columns)}) != size:
            continue
        answers.append(
            ["." * column + "Q" + "." * (size - column - 1) for column in columns]
        )
    return answers
```

This removes row and column conflicts by construction but still visits all
`n!` column permutations.

## Better approach: prune with occupied sets

```python
def solve_n_queens_sets(size: int) -> list[list[str]]:
    if not 1 <= size <= 9:
        raise ValueError("size must be between 1 and 9")

    answers: list[list[str]] = []
    placement: list[int] = []
    columns: set[int] = set()
    descending: set[int] = set()
    ascending: set[int] = set()

    def search(row: int) -> None:
        if row == size:
            answers.append(
                ["." * column + "Q" + "." * (size - column - 1) for column in placement]
            )
            return
        for column in range(size):
            if (
                column in columns
                or row - column in descending
                or row + column in ascending
            ):
                continue
            placement.append(column)
            columns.add(column)
            descending.add(row - column)
            ascending.add(row + column)
            search(row + 1)
            ascending.remove(row + column)
            descending.remove(row - column)
            columns.remove(column)
            placement.pop()

    search(0)
    return answers
```

Conflicts are rejected before recursion, so only legal prefixes are explored.

## Expert solution: bitmask backtracking

```python
def solve_n_queens(size: int) -> list[list[str]]:
    if not 1 <= size <= 9:
        raise ValueError("size must be between 1 and 9")

    full_mask = (1 << size) - 1
    placement: list[int] = []
    answers: list[list[str]] = []

    def search(columns: int, descending: int, ascending: int) -> None:
        if columns == full_mask:
            answers.append(
                ["." * column + "Q" + "." * (size - column - 1) for column in placement]
            )
            return
        available = full_mask & ~(columns | descending | ascending)
        while available:
            queen = available & -available
            available ^= queen
            placement.append(queen.bit_length() - 1)
            search(
                columns | queen,
                ((descending | queen) << 1) & full_mask,
                (ascending | queen) >> 1,
            )
            placement.pop()

    search(0, 0, 0)
    return answers
```

The three masks describe columns attacked in the current row. Shifting the
diagonal masks prepares their attacked columns for the next row, and every set
bit in `available` is exactly one legal choice.

**Complexity:** `O(n!)` worst-case search time and `O(n)` recursion space,
with constant-time conflict checks.

# Focus300 025: LeetCode 132 - Palindrome Partitioning II

**Source:** [LeetCode 132](https://leetcode.com/problems/palindrome-partitioning-ii/)  
**Difficulty:** Hard  
**Pattern:** minimum prefix cuts with palindrome expansion

## Exact contract

Return the minimum number of cuts needed to partition a string into nonempty
palindromic substrings.

## First principles

If `s[left:right+1]` is a palindrome, a partition ending there needs
`cuts[left]+1` cuts, where `cuts[left]` is the optimum for the prefix before
`left`. Set the empty-prefix value to `-1` so a palindrome starting at zero
needs zero cuts.

Palindromes can be generated by expanding around every odd and even center,
removing the need for a quadratic boolean table.

## Cases that decide correctness

- An empty or one-character string needs zero cuts.
- The entire string may already be a palindrome.
- Both odd- and even-length palindromes matter.
- Repeated characters create many overlapping palindromes.
- The DP counts cuts, not partition pieces.

## Brute force: enumerate every palindromic first piece

```python
def min_cut_brute(value: str) -> int:
    if not value:
        return 0

    def search(start: int) -> int:
        if start == len(value):
            return -1
        answer = len(value)
        for end in range(start + 1, len(value) + 1):
            piece = value[start:end]
            if piece == piece[::-1]:
                answer = min(answer, 1 + search(end))
        return answer

    return search(0)
```

The same suffix is recomputed across exponentially many partitions.

## Better approach: palindrome table plus prefix DP

```python
def min_cut_table(value: str) -> int:
    size = len(value)
    if size == 0:
        return 0
    palindrome = [[False] * size for _ in range(size)]
    cuts = list(range(size))
    for right in range(size):
        for left in range(right + 1):
            if value[left] == value[right] and (
                right - left <= 2 or palindrome[left + 1][right - 1]
            ):
                palindrome[left][right] = True
                cuts[right] = 0 if left == 0 else min(cuts[right], cuts[left - 1] + 1)
    return cuts[-1]
```

This is `O(n^2)` time and space.

## Expert solution: expand centers into one-dimensional cut DP

```python
def min_cut(value: str) -> int:
    size = len(value)
    if size == 0:
        return 0
    cuts = list(range(-1, size))
    for center in range(size):
        left = center
        right = center
        while left >= 0 and right < size and value[left] == value[right]:
            cuts[right + 1] = min(cuts[right + 1], cuts[left] + 1)
            left -= 1
            right += 1

        left = center - 1
        right = center
        while left >= 0 and right < size and value[left] == value[right]:
            cuts[right + 1] = min(cuts[right + 1], cuts[left] + 1)
            left -= 1
            right += 1
    return cuts[size]
```

Every palindrome is generated at its unique center, and its left-prefix cut
state is finalized before that center is processed.

**Complexity:** `O(n^2)` time and `O(n)` space.

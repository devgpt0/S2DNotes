# Focus300 180: LeetCode 50 - Pow(x, n)

**Source:** [LeetCode 50](https://leetcode.com/problems/powx-n/)  
**Difficulty:** Medium  
**Pattern:** binary exponentiation

## Exact contract

Given floating-point `base` and a 32-bit signed integer `exponent`, compute
`base` raised to `exponent`. Negative exponents mean the reciprocal power.
Source input excludes zero raised to a negative exponent.

## First principles

The binary representation of the absolute exponent selects powers
`base^(1), base^(2), base^(4), ...`. Square the current factor at every bit and
multiply it into the answer only when that bit is set. A negative exponent is
handled once by reciprocating the base.

## Cases that decide correctness

- Any nonzero base to exponent zero is `1.0`.
- A negative exponent uses `1 / base` and a positive magnitude.
- `-2^odd` is negative; `-2^even` is positive.
- The minimum 32-bit exponent must not be negated in fixed-width storage; Python
  integers safely hold its positive magnitude.
- Zero with a negative exponent is invalid.

## Brute force: multiply once per exponent unit

```python
def my_pow_brute(base: float, exponent: int) -> float:
    if base == 0.0 and exponent < 0:
        raise ZeroDivisionError("zero cannot have a negative exponent")

    factor = 1.0 / base if exponent < 0 else base
    answer = 1.0
    for _ in range(abs(exponent)):
        answer *= factor
    return answer
```

This takes `O(abs(exponent))` multiplications.

## Better transition: consume exponent bits instead of units

If an exponent is even, square the base and halve the exponent. If it is odd,
also multiply the current base into the answer. Each step removes one binary bit.

## Expert solution: iterative binary exponentiation

```python
def my_pow(base: float, exponent: int) -> float:
    if base == 0.0 and exponent < 0:
        raise ZeroDivisionError("zero cannot have a negative exponent")

    power = abs(exponent)
    factor = 1.0 / base if exponent < 0 else base
    answer = 1.0
    while power:
        if power & 1:
            answer *= factor
        factor *= factor
        power >>= 1
    return answer
```

At every iteration, `answer * factor^power` equals the requested positive-
magnitude power, so the final answer is exact up to floating-point arithmetic.

**Complexity:** `O(log abs(exponent))` time and `O(1)` space.

# Focus300 197: LeetCode 78 - Subsets

**Source:** [LeetCode 78](https://leetcode.com/problems/subsets/)  
**Difficulty:** Medium  
**Pattern:** power-set construction by iterative expansion or backtracking

## Exact contract

Return every subset of the distinct integers in `nums`. The empty subset must
be included, and the result order is unrestricted.

## First principles

A subset decision can be modeled as "include this number" or "skip it". Each
value doubles the number of reachable subsets, so the full answer is the power
set. Because the input values are distinct, every subset has one unique
membership pattern.

## Step-by-step transformation

1. Choose a start state such as a cell, node, or partial path.
2. Mark the state as visited or temporarily commit the choice.
3. Expand to valid neighbors or next choices while the invariant still holds.
4. Undo the temporary choice when the branch finishes, then return the collected answer.

These problems transform the input into output by exploring one branch at a time and backtracking whenever a branch can no longer produce a valid solution.

## Cases that decide correctness

- An empty input returns only the empty subset.
- A single value returns `[]` and `[value]`.
- The answer must include the empty subset exactly once.
- No subset may be repeated.
- Distinct input values mean index order, not value sorting, drives construction.

## Brute force: enumerate all binary include/skip masks

```python
def subsets_brute(nums: list[int]) -> list[list[int]]:
    if type(nums) is not list or not 0 <= len(nums) <= 10:
        raise ValueError("nums length must be between 0 and 10")
    if any(type(num) is not int or not -10 <= num <= 10 for num in nums):
        raise ValueError("nums must contain only integers from -10 through 10")
    if len(set(nums)) != len(nums):
        raise ValueError("nums must contain distinct values")

    answer: list[list[int]] = []
    count = len(nums)
    for mask in range(1 << count):
        subset: list[int] = []
        for index in range(count):
            if mask & (1 << index):
                subset.append(nums[index])
        answer.append(subset)
    return answer
```

This is conceptually simple but inspects every bit pattern explicitly.

## Better insight: grow the answer one number at a time

Start with `[[]]`. For each new value, copy the subsets already built and append
the new value to those copies. This avoids mask handling while preserving the
same power-set structure.

## Expert solution: iterative power-set expansion

```python
def subsets(nums: list[int]) -> list[list[int]]:
    if type(nums) is not list or not 0 <= len(nums) <= 10:
        raise ValueError("nums length must be between 0 and 10")
    if any(type(num) is not int or not -10 <= num <= 10 for num in nums):
        raise ValueError("nums must contain only integers from -10 through 10")
    if len(set(nums)) != len(nums):
        raise ValueError("nums must contain distinct values")

    answer: list[list[int]] = [[]]
    for num in nums:
        additions = [subset + [num] for subset in answer]
        answer.extend(additions)
    return answer
```

Each number doubles the current collection of subsets, so the construction is
linear in the number of emitted subsets.

**Complexity:** `O(n * 2^n)` time and `O(n * 2^n)` space for the output, with
`O(1)` extra working space beyond the answer.

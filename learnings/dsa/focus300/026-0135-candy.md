# Focus300 026: LeetCode 135 - Candy

**Source:** [LeetCode 135](https://leetcode.com/problems/candy/)  
**Difficulty:** Hard  
**Pattern:** satisfy local inequalities across increasing and decreasing slopes

## Exact contract

Give each child at least one candy. A child with a higher rating than an
adjacent child must receive more candy. Return the minimum total.

## First principles

Left-to-right constraints require increasing candy counts along rising rating
slopes. Right-to-left constraints do the same for falling slopes. Taking the
maximum required by both directions is the pointwise minimum satisfying every
edge inequality.

For constant space, track current rising length, falling length, and the last
peak. A descent adds its triangular contribution; when it is no longer than
the preceding ascent, the already-counted peak covers one unit of that descent.

## Cases that decide correctness

- Every child receives at least one candy.
- Equal ratings impose no inequality.
- Valleys reset both slope directions.
- A long descent may require increasing the earlier peak.
- One child requires exactly one candy.

## Brute force: repeatedly relax violated neighbor constraints

```python
def candy_brute(ratings: list[int]) -> int:
    candies = [1] * len(ratings)
    changed = True
    while changed:
        changed = False
        for index in range(len(ratings)):
            if (
                index > 0
                and ratings[index] > ratings[index - 1]
                and candies[index] <= candies[index - 1]
            ):
                candies[index] = candies[index - 1] + 1
                changed = True
            if (
                index + 1 < len(ratings)
                and ratings[index] > ratings[index + 1]
                and candies[index] <= candies[index + 1]
            ):
                candies[index] = candies[index + 1] + 1
                changed = True
    return sum(candies)
```

Repeated propagation can take `O(n^2)` time.

## Better approach: combine two directional requirements

```python
def candy_two_pass(ratings: list[int]) -> int:
    if not ratings:
        return 0
    left = [1] * len(ratings)
    for index in range(1, len(ratings)):
        if ratings[index] > ratings[index - 1]:
            left[index] = left[index - 1] + 1
    right = 1
    total = left[-1]
    for index in range(len(ratings) - 2, -1, -1):
        if ratings[index] > ratings[index + 1]:
            right += 1
        else:
            right = 1
        total += max(left[index], right)
    return total
```

This is `O(n)` time and `O(n)` space.

## Expert solution: one-pass slope accounting

```python
def candy(ratings: list[int]) -> int:
    if not ratings:
        return 0
    total = 1
    rising = 0
    falling = 0
    peak = 0
    for index in range(1, len(ratings)):
        if ratings[index] > ratings[index - 1]:
            rising += 1
            peak = rising
            falling = 0
            total += 1 + rising
        elif ratings[index] == ratings[index - 1]:
            rising = 0
            falling = 0
            peak = 0
            total += 1
        else:
            rising = 0
            falling += 1
            total += 1 + falling
            if falling <= peak:
                total -= 1
    return total
```

Each monotone run contributes its minimal staircase, with the shared peak
counted at the larger of its two required heights.

**Complexity:** `O(n)` time and `O(1)` space.

# Focus300 093: LeetCode 679 - 24 Game

**Source:** [LeetCode 679](https://leetcode.com/problems/24-game/)  
**Difficulty:** Hard  
**Pattern:** exhaustive binary-expression search with exact rationals

## Exact contract

Given exactly four integers from `1` through `9`, decide whether all four can
be used once to make `24` with binary `+`, `-`, `*`, `/`, and parentheses.
Division is ordinary rational division; concatenation and unary negation are
not operations supplied by the problem.

## First principles

Every fully parenthesized expression has a final binary operation. Recursively
splitting an ordered sequence at every boundary enumerates every expression
tree. Alternatively, working backward from the final operation means choosing
any pair, replacing it by a possible result, and repeating.

`Fraction` keeps equality and zero tests exact, avoiding floating-point
tolerances.

## Step-by-step transformation

1. Read the input and identify the smallest state that still determines the answer.
2. Process one element, node, or row at a time while preserving that state.
3. Discard work that can no longer change the result.
4. Convert the surviving state into the output the problem requests.

The examples and code below show this transformation on the specific problem instance.

## Cases that decide correctness

- Subtraction and division require both operand orders.
- Intermediate values may be zero, negative, or fractional.
- Division by an intermediate zero is forbidden.
- Every card must appear exactly once.
- Different parenthesizations can change the result.

## Brute force: permutations and every recursive split

```python
from fractions import Fraction
from itertools import permutations


def judge_point_twenty_four_brute(cards: list[int]) -> bool:
    if type(cards) is not list or len(cards) != 4:
        raise ValueError("cards must contain exactly four integers")
    if any(type(card) is not int or not 1 <= card <= 9 for card in cards):
        raise ValueError("each card must be an integer from 1 through 9")

    def combine(left: Fraction, right: Fraction) -> set[Fraction]:
        results = {left + right, left - right, left * right}
        if right != 0:
            results.add(left / right)
        return results

    def all_results(values: tuple[Fraction, ...]) -> set[Fraction]:
        if len(values) == 1:
            return {values[0]}
        results: set[Fraction] = set()
        for split in range(1, len(values)):
            for left in all_results(values[:split]):
                for right in all_results(values[split:]):
                    results.update(combine(left, right))
        return results

    target = Fraction(24)
    for ordering in permutations(Fraction(card) for card in cards):
        if target in all_results(ordering):
            return True
    return False
```

This repeats equivalent subexpressions across permutations and tree shapes.

## Better insight: contract any pair that could be the last operation's child

Choosing an unordered pair and generating both noncommutative orders covers
all expression trees without separately listing permutations or parentheses.
Canonical memoization removes repeated multisets of intermediate values.

## Expert solution: pair contraction with memoized rational states

```python
from fractions import Fraction


def judge_point_twenty_four(cards: list[int]) -> bool:
    if type(cards) is not list or len(cards) != 4:
        raise ValueError("cards must contain exactly four integers")
    if any(type(card) is not int or not 1 <= card <= 9 for card in cards):
        raise ValueError("each card must be an integer from 1 through 9")

    failed: set[tuple[Fraction, ...]] = set()

    def search(values: tuple[Fraction, ...]) -> bool:
        state = tuple(sorted(values))
        if len(state) == 1:
            return state[0] == 24
        if state in failed:
            return False

        for first_index in range(len(state)):
            for second_index in range(first_index + 1, len(state)):
                first = state[first_index]
                second = state[second_index]
                remaining = tuple(
                    value
                    for index, value in enumerate(state)
                    if index not in (first_index, second_index)
                )
                candidates = {
                    first + second,
                    first * second,
                    first - second,
                    second - first,
                }
                if second != 0:
                    candidates.add(first / second)
                if first != 0:
                    candidates.add(second / first)
                if any(search((*remaining, result)) for result in candidates):
                    return True

        failed.add(state)
        return False

    return search(tuple(Fraction(card) for card in cards))
```

Each recursion reduces the number of values by one, and every possible final
binary operation is represented by one chosen pair.

**Complexity:** constant for the source's four cards; for `n` generalized
values, the search is exponential, with memoization over rational multisets.

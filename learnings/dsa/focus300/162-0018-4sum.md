# Focus300 162: LeetCode 18 - 4Sum

**Source:** [LeetCode 18](https://leetcode.com/problems/4sum/)  
**Difficulty:** Medium  
**Pattern:** sorted fixed prefixes plus two pointers

## Exact contract

Return every distinct value quadruplet obtainable from four distinct indices
whose sum equals `target`. Duplicate quadruplets are forbidden; result order is
otherwise unrestricted. The input list must remain unchanged.

## First principles

After sorting a copy, fix the first two indices. The remaining pair must hit a
known residual target, and its sum changes monotonically as inward pointers
move. Skipping equal fixed values and equal values after a match ensures one
result per value quadruplet.


## Classroom board: turn a range into two prefixes

```text
a subarray sum becomes prefix[right] - prefix[left], so one prefix table
replaces many repeated range scans.
```



## Step-by-step transformation

1. Load the current candidates into a stack, queue, heap, or window.
2. Push or pop the structure while the current element keeps the invariant true.
3. Drop stale candidates and keep only the ones that can still affect the answer.
4. Read the final top, window score, or popped order as the output.

These problems transform the input by keeping just the active frontier of candidates instead of rescanning the whole array every time.

## Cases that decide correctness

- Fewer than four values returns an empty list.
- Repeated values may be required, such as `[2, 2, 2, 2]`.
- Distinct indices, not distinct values, are selected.
- Large positive and negative values must sum without fixed-width overflow.
- Sorting a copy avoids mutating the caller's list.

## Brute force: enumerate four indices and deduplicate values

```python
from itertools import combinations


def four_sum_brute(numbers: list[int], target: int) -> list[list[int]]:
    if type(numbers) is not list or not 1 <= len(numbers) <= 200:
        raise ValueError("numbers length must be between 1 and 200")
    if any(
        type(value) is not int or not -1_000_000_000 <= value <= 1_000_000_000
        for value in numbers
    ):
        raise ValueError("numbers must be integers in the source range")
    if type(target) is not int or not -1_000_000_000 <= target <= 1_000_000_000:
        raise ValueError("target must be an integer in the source range")

    quadruplets: set[tuple[int, int, int, int]] = set()
    for indices in combinations(range(len(numbers)), 4):
        values = sorted(numbers[index] for index in indices)
        if sum(values) == target:
            quadruplets.add((values[0], values[1], values[2], values[3]))
    return [list(values) for values in sorted(quadruplets)]
```

This costs `O(n^4)` time before output deduplication.

## Better insight: two fixed values reduce the suffix to sorted 2Sum

For each fixed pair, move the remaining endpoints according to whether their
four-value total is below or above the target.

## Expert solution: two fixed loops and a two-pointer suffix

```python
def four_sum(numbers: list[int], target: int) -> list[list[int]]:
    if type(numbers) is not list or not 1 <= len(numbers) <= 200:
        raise ValueError("numbers length must be between 1 and 200")
    if any(
        type(value) is not int or not -1_000_000_000 <= value <= 1_000_000_000
        for value in numbers
    ):
        raise ValueError("numbers must be integers in the source range")
    if type(target) is not int or not -1_000_000_000 <= target <= 1_000_000_000:
        raise ValueError("target must be an integer in the source range")

    ordered = sorted(numbers)
    answer: list[list[int]] = []
    for first in range(len(ordered) - 3):
        if first > 0 and ordered[first] == ordered[first - 1]:
            continue
        for second in range(first + 1, len(ordered) - 2):
            if second > first + 1 and ordered[second] == ordered[second - 1]:
                continue
            left = second + 1
            right = len(ordered) - 1
            while left < right:
                total = (
                    ordered[first] + ordered[second] + ordered[left] + ordered[right]
                )
                if total < target:
                    left += 1
                elif total > target:
                    right -= 1
                else:
                    answer.append(
                        [ordered[first], ordered[second], ordered[left], ordered[right]]
                    )
                    left_value = ordered[left]
                    right_value = ordered[right]
                    while left < right and ordered[left] == left_value:
                        left += 1
                    while left < right and ordered[right] == right_value:
                        right -= 1
    return answer
```

The sorted pointer rule exhausts every suffix pair for each unique fixed pair,
while duplicate skips make every emitted quadruplet unique.

**Complexity:** `O(n^3)` time and `O(n)` space for the sorted copy, excluding
output.

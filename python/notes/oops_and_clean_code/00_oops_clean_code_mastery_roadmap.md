# OOP and Clean Code - Mastery Roadmap

This roadmap organizes the OOP module into a complete mastery path.

## 1) Mastery Outcome

You can:
- model domains with clear class boundaries.
- choose between inheritance, composition, and strategy patterns correctly.
- design abstraction-first APIs using ABC/Protocol.
- apply SOLID without overengineering.
- refactor code smells safely with tests.

## 4) Study Order

1. Class basics, state, encapsulation
2. Abstraction and composition-first design
3. Inheritance/MRO and polymorphism
4. SOLID and design patterns
5. Dataclasses + protocols + DI
6. Refactoring and case-study practice

## 5) Interview Checklist

1. Explain composition vs inheritance with tradeoffs.
2. Explain LSP contract violations with real examples.
3. Explain ABC vs Protocol.
4. Explain how DI improves testability.
5. Explain common OOP smells and safe refactor steps.

## 6) Production Checklist

1. Responsibilities are explicit and small.
2. Dependencies are injected, not hardcoded.
3. Domain invariants are validated at boundaries.
4. Abstractions are stable and implementation-agnostic.
5. Unit and contract tests protect refactors.

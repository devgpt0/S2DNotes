# 99 - Build a Course Dashboard in 60 Minutes

## Project Overview

Build a responsive course dashboard with shadcn/ui, React, strict TypeScript, Tailwind CSS, and Zod. Users can view course cards and add a validated course through an accessible dialog.

shadcn/ui is source code, not a remote component package. The CLI copies UI primitives into the project. This lesson shows every file you author and names every generated primitive it depends on.

## What You Will Learn

- how shadcn/ui source ownership differs from a component dependency
- `components.json`, aliases, theme tokens, and the `cn` helper
- domain components built from small UI primitives
- strict form validation without coercion
- controlled dialog state, focus behavior, and visible errors
- intrinsic responsive layouts and finite component variants

## File: `src/course.ts`

```typescript
import { z } from "zod";

export const COURSE_STATUSES = ["draft", "published"] as const;

export const courseInputSchema = z.object({
  title: z.string().trim().min(2).max(80),
  description: z.string().trim().min(10).max(200),
}).strict();

export type CourseStatus = (typeof COURSE_STATUSES)[number];
export type CourseInput = z.infer<typeof courseInputSchema>;
export type Course = Readonly<CourseInput & {
  id: string;
  status: CourseStatus;
}>;
```

Concepts learned from this file:

- one schema validates runtime form data and derives its TypeScript type.
- `.strict()` rejects unexpected object keys.
- no coercion is enabled; wrong runtime types fail.
- course status is a finite union, not any string.

## File: `src/components/CreateCourse.tsx`

```tsx
import { useState, type FormEvent } from "react";
import { courseInputSchema, type CourseInput } from "@/course";
import { Button } from "@/components/ui/button";
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

type CreateCourseProps = Readonly<{
  onCreate: (input: CourseInput) => void;
}>;

export function CreateCourse({ onCreate }: CreateCourseProps) {
  const [open, setOpen] = useState(false);
  const [error, setError] = useState("");

  function submit(event: FormEvent<HTMLFormElement>): void {
    event.preventDefault();
    const form = event.currentTarget;
    const data = new FormData(form);
    const result = courseInputSchema.safeParse({
      title: data.get("title"),
      description: data.get("description"),
    });

    if (!result.success) {
      setError("Enter a 2-80 character title and a 10-200 character description.");
      return;
    }

    onCreate(result.data);
    form.reset();
    setError("");
    setOpen(false);
  }

  return (
    <Dialog open={open} onOpenChange={setOpen}>
      <DialogTrigger asChild>
        <Button>Create course</Button>
      </DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Create a course</DialogTitle>
          <DialogDescription>Add the title and learner-facing description.</DialogDescription>
        </DialogHeader>
        <form className="grid gap-4" onSubmit={submit}>
          <div className="grid gap-2">
            <Label htmlFor="course-title">Title</Label>
            <Input id="course-title" name="title" minLength={2} maxLength={80} required />
          </div>
          <div className="grid gap-2">
            <Label htmlFor="course-description">Description</Label>
            <Input id="course-description" name="description" minLength={10} maxLength={200} required aria-describedby="course-error" />
          </div>
          <p id="course-error" className="text-sm text-destructive" role="alert">{error}</p>
          <DialogFooter>
            <Button type="submit">Save course</Button>
          </DialogFooter>
        </form>
      </DialogContent>
    </Dialog>
  );
}
```

Concepts learned from this file:

- controlled dialog state closes only after successful validation.
- FormData values remain runtime values until Zod validates them.
- the field error is visible near the form instead of existing only in a toast.
- shadcn's Dialog primitive owns focus trap, Escape behavior, labelling, and focus return.

## File: `src/App.tsx`

```tsx
import { useState } from "react";
import { CourseCard } from "@/components/CourseCard";
import { CreateCourse } from "@/components/CreateCourse";
import type { Course, CourseInput } from "@/course";

const initialCourses: readonly Course[] = [
  {
    id: "java-foundations",
    title: "Java Foundations",
    description: "Learn variables, methods, control flow, and objects step by step.",
    status: "published",
  },
  {
    id: "react-accessibility",
    title: "React Accessibility",
    description: "Build components that work with keyboard and assistive technology.",
    status: "draft",
  },
];

export default function App() {
  const [courses, setCourses] = useState(initialCourses);
  const [message, setMessage] = useState("");

  function createCourse(input: CourseInput): void {
    setCourses((current) => [
      ...current,
      { ...input, id: crypto.randomUUID(), status: "draft" },
    ]);
    setMessage(`${input.title} created as a draft`);
  }

  return (
    <main className="mx-auto w-full max-w-6xl space-y-8 px-4 py-10 sm:px-6 lg:px-8">
      <header className="flex flex-wrap items-end justify-between gap-4">
        <div>
          <p className="font-semibold text-primary">shadcn/ui project</p>
          <h1 className="text-3xl font-bold tracking-tight">Course dashboard</h1>
          <p className="mt-2 text-muted-foreground">Manage learner-facing course content.</p>
        </div>
        <CreateCourse onCreate={createCourse} />
      </header>

      <p role="status" className="min-h-6 text-sm">{message}</p>

      <section aria-labelledby="courses-heading">
        <h2 id="courses-heading" className="sr-only">Courses</h2>
        <div className="grid grid-cols-[repeat(auto-fit,minmax(min(100%,17rem),1fr))] gap-4">
          {courses.map((course) => <CourseCard key={course.id} course={course} />)}
        </div>
      </section>
    </main>
  );
}
```

Concepts learned from this file:

- feature state stays in the smallest common owner.
- domain creation receives already validated input.
- an intrinsic grid responds to available space without JavaScript breakpoints.
- stable IDs preserve card identity and create safe resource links.

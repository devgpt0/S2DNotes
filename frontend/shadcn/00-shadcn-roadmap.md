# shadcn/ui - Beginner to Expert Roadmap

These notes target the shadcn CLI 4.13.x with React 19 and Tailwind CSS 4.

shadcn/ui is not a traditional component package you import forever. The CLI adds component source code to your project, so your team owns and can customize it.

## Prerequisites

HTML accessibility, standard CSS, Tailwind, TypeScript, React props/state/forms/composition, and basic testing.

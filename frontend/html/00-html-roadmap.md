# HTML - Beginner to Expert Roadmap

HTML gives a web page meaning and structure. It is not a programming language and it should not be used only to control appearance.

## Learning Goal

You should be able to create a page that remains understandable without CSS, works with a keyboard and screen reader, loads efficiently, and gives search engines useful structure.

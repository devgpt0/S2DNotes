# Tailwind CSS - Beginner to Expert Roadmap

Tailwind is a utility-first CSS framework. You compose small classes in markup and Tailwind generates the CSS used by your project.

These notes target Tailwind CSS 4.3.x. Learn standard CSS first; Tailwind class names are shortcuts for CSS concepts, not replacements for understanding them.

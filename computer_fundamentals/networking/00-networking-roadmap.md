# Networking Roadmap

This track explains how bytes travel across unreliable networks and how application protocols build useful guarantees on top.

1. [TCP/IP, UDP, DNS, and connection behavior](01-tcp-ip-udp-dns-and-connections.md)
2. [HTTP/1.1, HTTP/2, HTTP/3, QUIC, WebSockets, and gRPC](02-application-protocols-http-quic-websockets-grpc.md)
3. [TLS, load balancing, congestion control, and production reliability](03-tls-load-balancing-congestion-and-reliability.md)
4. [Networking interview preparation and request diagnosis](04-networking-interview-preparation.md)

## Learning Flow

```text
names -> IP routes -> transport -> encrypted connection -> application protocol -> load-balanced service
```

## Mastery Outcome

You can trace a request from DNS lookup to response, compare transport/application protocols, reason about latency and loss, and diagnose where an end-to-end request is failing.
